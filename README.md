# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Imcharan17/Portfoilo-react.git
```

---

## Install Dependencies

```bash
cd Portfoilo-react

npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Build Project

```bash
npm run build
```

---

## Preview Production Build

```bash
npm run preview
```

---

# ⚙ Environment Variables

The frontend expects the backend at

```
http://localhost:5000
```

You can change it using

```
VITE_API_URL
```

Example

```
VITE_API_URL=http://localhost:5000
```
